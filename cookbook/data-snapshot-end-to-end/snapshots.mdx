# 3. Snapshot extraction

**Question:** How are figures and tables extracted as images?

## Rationale

PDF pages are rendered as red, green, and blue (RGB) images before the detector runs. The detector returns a class, confidence, and normalized rectangle for each retained region. Normalized coordinates describe the left, top, right, and bottom edges as fractions of page width and height, measured from the top-left corner.

The production workflow crops these rectangles directly. It does not pad boxes, merge panels, or persist page coordinates. The semantic JSON generated in the next stage describes image content and serves a different purpose.

## Target state

- The snapshot-only command saves inspectable PNG files.
- The curator can distinguish the target chart and table from irrelevant detections.

## Maturity levels

| Level | Steps |
|---|---|
| **Foundational** | A curator identifies analytical regions on source pages and saves or inspects example data snapshots manually. |
| **AI-ready** | A developer runs the documented detector, retains its candidate PNG outputs, and checks selected data snapshots against their source pages before further processing. |
| **AI-native** | An organization integrates detection into document intake and checks candidate relevance and data snapshot completeness under human review. Automatic quality monitoring is not supplied by this example. |

:::info[Running example]
The snapshot-only run processes the twelve-page sample PDF used in the tutorial and saves seven figure-labelled candidate images and one table-labelled candidate image. The cover photograph is `figure_000`. The chart `figure_001` and demographic table `table_000`, both from PDF page 4, are the two data snapshots selected for the next chapter.
:::

## Recipes

<Recipe title="3.1 Run snapshot-only extraction" level="AI-ready" skills="Developer and data curator" time="Ten minutes to prepare the command; detector execution time varies">

**Result:** The document has been processed without a metadata API request.

The following command uses the PDF acquired in [chapter 1](./preparation.mdx) and the default settings selected in [chapter 2](./models.mdx). `--output-dir` is the root; the package appends the detector name and `snapshots/`. The source filename stem is its name without the `.pdf` extension and becomes the prefix of each data snapshot filename. It renders at 300 DPI by default. All twelve pages are processed because the CLI has no page-range option.

```bash
python -m ai4data.data_snapshot.extract_data_snapshot \
  --input=data/policy_brief_on_shona_community_from_stateless_to_citizens.pdf \
  --output-dir=output/cookbook-shona --model=doclayoutyolo --device=cpu
```

1. Use a fresh destination so that an earlier file does not cause the entire PDF to be skipped.
2. Run the command and inspect progress and printed paths. An input can also be a directory searched recursively for PDFs.
3. Keep source filename stems unique across a directory run, including subdirectories; outputs are flattened into one model directory.
4. Open the saved candidate images before sending any to a metadata provider.

**Worked example.** The recorded run saved `figure_000.png` through `figure_006.png` and `table_000.png`, each prefixed by the complete PDF stem. `figure_000` is the cover photograph, `figure_001` is the chart on PDF page 4, and `table_000` is the demographic table on that same page. These counts describe saved detector outputs; the photograph demonstrates why human review is still needed.

**What this does not do.** This command does not generate metadata or persist page coordinates, confidence scores, page images, or a quality report. No OCR stage is performed.

</Recipe>

<Recipe title="3.2 Inspect the figure and table data snapshots" level="AI-ready" skills="Developer and data curator" time="Fifteen minutes to inspect the two selected data snapshots">

**Result:** The two examples have been checked against their source page.

The figure counter and table counter are independent and start at zero. They continue across the document, so the printed Figure 1 can have the filename suffix `figure_001`. The index does not encode a page number or the printed caption.

1. Open the [source page](pathname:///cookbook-files/data-snapshot-end-to-end/shona-page-4.webp), the [figure data snapshot](pathname:///cookbook-files/data-snapshot-end-to-end/policy_brief_on_shona_community_from_stateless_to_citizens_figure_001.png), and the [table data snapshot](pathname:///cookbook-files/data-snapshot-end-to-end/policy_brief_on_shona_community_from_stateless_to_citizens_table_000.png).
2. Check the chart's series legend, horizontal period labels, vertical percentage scale, and both population-group panels.
3. Check that the table retains its five demographic rows and both year columns. Compare the image with the page to identify excluded captions or source notes.
4. Record quality observations separately and preserve the produced data snapshot.

**Worked example.** Both selected data snapshots retain their main analytical content but exclude their printed captions and source notes. This is a useful limitation: a later metadata model receives only that image and cannot be expected to recover those excluded details.

The two selected PNG data snapshots now provide the image inputs for [chapter 4](./metadata.mdx). The full detector-output folder remains available for inspection; selecting these two images does not remove or reclassify any of its other candidates.

## Implementation options

Use `--dpi` to choose a positive rendering resolution and a new output root to compare settings safely. Higher resolution consumes more rendering memory and storage; inference also uses the adapter's own image-size setting. The lower-level `extract_snapshots` API accepts a custom detector, while `run_extraction` provides the model-scoped directory convention.

## Common mistakes

- Reading the filename index as a printed figure number points to the wrong artifact.
- Counting every figure-labelled candidate image as analytical content hides false positives.
- Assuming captions are automatically included can make metadata incomplete.

## Verification

- Inspect the printed paths and the `output/cookbook-shona/doclayoutyolo/snapshots/` directory. The recorded example contains seven figure-labelled PNGs and one table-labelled PNG; investigate differences before relying on the example filenames.
- Open `figure_001` and `table_000` beside PDF page 4. The selected chart should retain its panels and legend, and the table should retain its five rows and both year columns.
- Check the page beyond each data snapshot boundary. The recorded data snapshots omit their printed captions and source notes, while the cover photograph is an irrelevant analytical candidate.
