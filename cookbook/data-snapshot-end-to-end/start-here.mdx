# Self-assessment

Select the statement that best describes the organization's current practice,
one per chapter. The four options progress from **Not yet** through
**Foundational**, **AI-ready**, and **AI-native**. The result shows the level
for each chapter and suggests where to begin. Answers are stored in this
browser only.

The more advanced options describe organizational practices that may require
integration beyond the production package. They do not indicate that the
cookbook implements monitoring, automated review, or a second-stage
classifier. The last question concerns the evaluation and planning of
improvements, so it can be answered without having built a proposed feature.

## Interpretation of the result

- A **Not yet** result in [chapter 1](./preparation.mdx) points to the source
  PDF and environment preparation needed before the commands can be followed.
- The default route through [chapter 2](./models.mdx) through [chapter 4](./metadata.mdx) establishes the
  configuration, produces candidate data snapshots, and describes the two selected
  images. Optional model changes can wait until the example is understood.
- [Chapter 5](./review.mdx) remains relevant even when commands and schema
  validation succeed. Its observations show the difference between a saved
  output and one suitable for the intended use.
- [Chapter 6](./combined.mdx) becomes useful after the separate stages have
  been understood. [Chapter 7](./operation.mdx) addresses reruns and request
  scope; neither topic requires running the unexecuted combined example.
- A lower result in [chapter 8](./roadmap.mdx) suggests starting with recorded
  problems and a defined evaluation plan. It does not imply that the
  organization should already have implemented the proposed classifier.

These results guide reading priorities. They are not a certification of output
quality or a requirement to reach every level before using the worked example.
